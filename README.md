# Elite 102 Banking App

## PROJECT DESCRIPTION
This is a simple command-line banking application built with Python and the SQLite library that allows users to create and manage bank accounts! It supports core operations like deposits, withdrawals, and balance tracking with persistent data storage via a database.

## SETUP INSTRUCTIONS
Clone this repository and run the Python file, banking_app.py. The SQLite database will be automatically created on the first run.

##### FEATURES: Create accounts, deposit and withdraw funds with validation, and check balances. View all accounts and track transactions stored in a local SQLite database.
